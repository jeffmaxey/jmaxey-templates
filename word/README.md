# Word templates

## Report outline
Title page - Document control (author, version, date) - Table of contents -
Executive summary - Background - Method - Findings - Recommendations - Appendices.

## Memo outline
To / From / Date / Subject - Purpose - Key points - Action required.

Standards: use built-in Heading 1-3 styles, one body style, captions on figures
and tables; save as `.dotx`.
